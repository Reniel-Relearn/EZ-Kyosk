# Generated Menu Asset Provenance

The eight menu photographs in `src/assets/menu/` were created with the built-in image generation workflow for this prototype, then resized to a maximum 960-pixel edge and saved as quality-optimized JPEG files. No external image CDN is required at runtime.

## Shared prompt direction

```text
Use case: product-mockup
Asset type: self-ordering kiosk menu card product photo
Scene/backdrop: warm ivory stone café tabletop with a softly blurred elegant café setting
Style/medium: photorealistic commercial food photography, editorial luxury café aesthetic
Composition/framing: square close three-quarter angle, full subject visible with a clean responsive menu-card crop
Lighting/mood: soft warm window light, refined and inviting
Color palette: ivory, espresso brown, caramel gold, and natural food colors
Constraints: no text, no logos, no people, no watermark
```
